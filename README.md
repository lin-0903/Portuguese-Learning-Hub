# 葡语超简单 · Brazilian Portuguese Learning Hub 🇧🇷

零基础巴西葡萄牙语互动复习网站，包含 **20 个学习单元、256 张词汇卡和 77 道练习题**。

## 在线访问

启用 GitHub Pages 后：

https://lin-0903.github.io/Portuguese-Learning-Hub/

## 发布步骤（仅首次需要）

1. 打开仓库 **Settings → Pages**。
2. 在 **Build and deployment** → **Source** 选择 **Deploy from a branch**。
3. 在 **Branch** 选择 `main` 和 `/(root)`，点击 **Save**。
4. 等待 GitHub Pages 部署完成，再打开上面的地址。

## 使用说明

- 主页是 `index.html`，无需构建环境，不依赖外部脚本。
- 可在 Chrome、Safari 和手机浏览器使用；发音功能由浏览器的语音合成提供。
- 学习进度保存在浏览器 `localStorage`，**不会自动跨设备同步**。
- 换设备或清理浏览器前，请先在网站的「语法速查」中**导出 JSON 进度备份**，到新设备上导入。首次从本地 HTML 切换至 GitHub Pages 时也需要使用备份迁移。
- 更新网站时保留站点地址及数据结构，以尽量延续原来的练习记录。

巴西葡语发音、打招呼、冠词和名词性数、人称代词、规则和不规则动词现在时、ser/estar、介词和缩合、所有格、疑问句、数字、时间、地点、国家和国籍等。更多课程可逐步扩充。
